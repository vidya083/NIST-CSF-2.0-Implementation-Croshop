# NIST CSF 2.0 Implementation: Croshop Private Limited
**Securing a Social-Impact Startup through Framework-Driven Governance**

## Project Overview
This project demonstrates a full-lifecycle implementation of the **NIST CSF 2.0** framework for a decentralized social-impact business. The goal was to transition the organization from informal operations to a resilient, audit-ready security posture.

## The Challenge
* **Decentralized Team:** Managing 60+ artisans and partners across remote locations.
* **High-Value Assets:** Protecting proprietary crochet patterns (Intellectual Property) and artisan payment logs (PII/Financial Data).
* **Resource Constraints:** Implementing enterprise-grade security on a startup budget.

## Milestone 1: Identify (ID.AM)
I established a comprehensive **Enterprise Asset Register**, mapping 12+ critical assets to NIST categories to ensure visibility into the organizational risk surface.
> [View Step 1 Detailed PDF](./Project-Documentation/Step-1-Asset-Inventory.pdf)

## Milestone 2: Govern (GV.PO)
I architected a **User Access Management Policy** aligned with NIST PR.AA and GV.RR, enforcing Least-Privilege and MFA requirements for all critical administrative functions.
> [View Step 2 Detailed PDF](./Project-Documentation/Step-2-Access-Policy.pdf)

## Technical Stack
* **Framework:** NIST CSF 2.0
* **Documentation:** Markdown, Microsoft Word (PDF Export)
* **Analysis:** Excel (Risk Weighting & Asset Tagging)
  
## Milestone 3: Protect & Assess (PR)
I conducted a **Gap Assessment** to evaluate Croshop’s current security maturity against NIST CSF 2.0 standards. This phase focused on identifying high-risk areas in Identity Management (PR.AA) and Data Security (PR.DS).
> [View Step 3 Detailed PDF](./Project-Documentation/Step-3-Gap-Assessment.pdf)
